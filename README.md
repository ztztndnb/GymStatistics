# GymStatistics

GymStatistics 是一款离线优先的个人健身记录应用。训练记录和计划留在手机上；需要分析食物时，再用 AI 相机拍照或从相册选图。

你可以按日期记录动作、查看历史趋势和训练肌群，在手动模式与按周重复的计划模式之间切换，也可以通过局域网在电脑浏览器中查看、导出和导入数据。AI 食物分析支持食物照片、配料表和营养成分表，需要网络连接及自行配置的 DeepSeek API Key。

## 主要功能

### 记录每日训练

- 按日期记录训练动作，每次添加一条动作记录。
- 支持重量、距离等数值，以及单位、次数、组数和备注。
- 记录默认保存到当前选中的日期，无需重复填写日期。
- 支持编辑和删除单条动作记录，删除前会进行确认。
- 可为动作选择训练肌群，之后可在历史记录中查看和修改。

### 快速切换日期

- 顶部日期栏可打开月历，支持切换月份和回到今天。
- 周日期栏可以快速选择一周内的日期，也可以左右滑动浏览前后整周；仅浏览周时不会改变当前训练日期。
- 在训练记录区域左右滑动即可切换前一天或后一天。
- 页面会跟随手指移动；松手时会结合拖动距离、速度和方向决定切换或回弹。

### 历史记录与趋势

- 历史页面会按动作名称汇总所有训练记录。
- 搜索支持动作名称和肌群名称，也支持中文、拼音、首字母及模糊匹配。
- 点击动作可查看全部历史记录。
- 支持按单位分别查看数据趋势和总次数趋势。
- 点击历史记录即可将数据带回记录页面，方便再次使用。

### 训练计划

- 点击首页左上角的“GymStatistics”展开侧边栏，从“训练计划”进入按周一至周日重复使用的计划编辑页。
- 支持手动添加动作，也可以从历史动作中带入最近一次的重量、次数、组数和肌群等数据。
- 可在设置中切换“手动模式”和“计划模式”，默认进入手动模式。
- 计划模式中点击“完成并记录”会将预设动作写入当前日期；完成后的计划动作会折叠显示。
- 计划生成的实际记录会在手动模式中显示“计划”标识，并与普通记录使用同一套历史、编辑、删除和统计数据。
- 手动添加同名动作时会询问是否关联到当天尚未完成的计划动作。

### 肌群与疲劳提醒

- 动作可以关联一个或多个肌群。
- 同一肌群在最近严格不足 3 天内训练过时，会显示疲劳提醒。
- 疲劳提醒可以在动作详情页单独关闭。

### AI 食物分析

在首页顶部“历史”旁点击相机图标，即可进入 AI 相机：

- 点击中央快门拍摄，或从左下角相册选择已有图片；右上角钥匙图标用于配置 API Key，右下角可查看食物分析历史。
- 识别食物、配料表和营养成分表。
- 相机预览会按屏幕比例居中裁剪，拍摄后的图片也会使用相同裁剪区域。
- 拍摄后先进入图片确认页面，可重新拍摄，也可以顺时针或逆时针旋转图片；确认后才会发送给 AI 分析。
- 相机控件进入时有淡入动效，按下快门与完成拍摄均有视觉反馈；旋转照片时会平滑过渡。
- 将能量、蛋白质、脂肪、碳水等数据统一按每 100g 展示。
- 分析完成后会显示包含原图、整份热量、三大营养素、食材明细和已有营养信息的报告。
- 每个食材可以单独修改重量及营养素系数，应用会重新计算整份食物的总重量、总热量和总营养素。
- 将确认后的结果与压缩后的原图保存到独立的“食物分析历史”，不会写入训练日期。
- 从食物分析历史打开报告、编辑食材或返回相机时，页面使用左右滑动转场。
- 使用前可在相机钥匙按钮或侧边栏“设置”中配置 DeepSeek API Key，Key 会在本机加密保存。

二维码和条形码不会被用于查询营养数据。

### 离线优先

- 训练数据保存在手机本地。
- 没有网络也可以正常记录、查看和编辑训练。
- 不需要注册账号，也不会将数据自动上传到云端。

### 局域网同步

手机和电脑连接到同一个 Wi-Fi 或局域网后，可以从侧边栏“设置”进入“局域网同步”：

- 手机作为数据源，电脑浏览器实时查看训练数据。
- 支持导出 JSON 和 CSV 文件。
- 支持从电脑选择 JSON 文件导回手机。
- 导入时可以选择全部导入或按日期导入；遇到重复日期会提示处理方式。
- 同步页面可以复制访问地址，默认端口为 `8931`。

## 使用方法

### 记录训练

1. 在首页选择训练日期。
2. 点击“记录动作”。
3. 填写动作、数值、次数、组数和备注。
4. 选择训练肌群后保存。

### 查看历史

1. 点击首页右上角的“历史”。
2. 在搜索框输入动作名称或肌群名称。
3. 点击动作查看历史记录和趋势图。

### 在电脑上查看数据

1. 确认手机和电脑连接到同一个局域网。
2. 点击首页左上角的“GymStatistics”，在“设置”中打开“局域网同步”。
3. 打开同步开关并复制页面显示的地址。
4. 在电脑浏览器中访问该地址。

### 分析食物

1. 在首页顶部“历史”旁点击相机图标。
2. 首次使用时，点击相机右上角的钥匙图标配置 DeepSeek API Key；也可提前在“设置”中配置。
3. 点击中央快门拍照，或点击左下角“相册”选取图片。
4. 拍摄后先在确认页面检查图片，必要时旋转或重新拍摄；确认后才开始分析。从相册选图则直接开始分析。
5. 查看报告，按需单独修改食材重量及每 100g 的营养数据。
6. 点击“保存到食物分析历史”，保存结果和照片副本；分析结果不会自动加入当天训练记录。

## 数据与隐私

- 数据默认只保存在本机应用目录中。
- 拍摄照片经确认、或从相册选取图片后，应用会将图片发送给 DeepSeek。保存分析结果时，照片副本会保存在本机的食物分析历史中。
- 训练记录不需要网络连接；AI 食物分析需要网络连接和 DeepSeek API Key。
- 局域网同步仅在你主动打开后启用。
- 手机是唯一的数据源，电脑端主要用于查看、导出和导入。
- 无需注册应用账号；训练数据不会自动上传到云端。
