# GymStatistics

GymStatistics 是一款面向个人使用的 Android 训练记录应用。

它可以在没有网络的情况下记录每日训练，按日期查看训练历史，追踪动作趋势，标记训练肌群，并通过局域网在电脑浏览器中查看、导出和导入数据。应用还支持使用 DeepSeek 分析食物照片、配料表和营养成分表。

## 主要功能

### 记录每日训练

- 按日期记录训练动作，每次添加一条动作记录。
- 支持重量、距离等数值，以及单位、次数、组数和备注。
- 记录默认保存到当前选中的日期，无需重复填写日期。
- 支持编辑和删除单条动作记录，删除前会进行确认。
- 可为动作选择训练肌群，之后可在历史记录中查看和修改。

### 快速切换日期

- 顶部日期栏可打开月历，支持切换月份和回到今天。
- 周日期栏可以快速选择一周内的日期。
- 在训练记录区域左右滑动即可切换前一天或后一天。
- 页面会跟随手指移动；松手时会结合拖动距离、速度和方向决定切换或回弹。

### 历史记录与趋势

- 历史页面会按动作名称汇总所有训练记录。
- 搜索支持动作名称和肌群名称，也支持中文、拼音、首字母及模糊匹配。
- 点击动作可查看全部历史记录。
- 支持按单位分别查看数据趋势和总次数趋势。
- 点击历史记录即可将数据带回记录页面，方便再次使用。

### 肌群与疲劳提醒

- 动作可以关联一个或多个肌群。
- 同一肌群在最近严格不足 3 天内训练过时，会显示疲劳提醒。
- 疲劳提醒可以在动作详情页单独关闭。

### AI 食物分析

在首页顶部“历史”旁点击相机图标，可以：

- 直接拍摄食物照片，或从相册选择已有图片。
- 进入应用内相机取景界面：左下角相册、右上角 API Key 设置、右下角食物分析历史。
- 识别食物、配料表和营养成分表。
- 将能量、蛋白质、脂肪、碳水等数据统一按每 100g 展示。
- 分析完成后会先显示包含原图、整份热量、三大营养素、食材明细和已有营养信息的报告。
- 修改材料重量和任意营养素，应用会重新计算整份食物的总重量与总营养；编辑完成后会回到报告确认。
- 将确认后的结果与压缩后的原图保存到独立的“食物分析历史”，不会写入训练日期。
- 使用前在页面中配置 DeepSeek API Key，Key 会在本机加密保存。

二维码和条形码不会被用于查询营养数据。

### 离线优先

- 训练数据保存在手机本地。
- 没有网络也可以正常记录、查看和编辑训练。
- 不需要注册账号，也不会将数据自动上传到云端。

### 局域网同步

手机和电脑连接到同一个 Wi-Fi 或局域网后，可以在 App 中打开“局域网同步”：

- 手机作为数据源，电脑浏览器实时查看训练数据。
- 支持导出 JSON 和 CSV 文件。
- 支持从电脑选择 JSON 文件导回手机。
- 导入时可以选择全部导入或按日期导入；遇到重复日期会提示处理方式。
- 同步页面可以复制访问地址，默认端口为 `8931`。

## 使用方法

### 记录训练

1. 在首页选择训练日期。
2. 点击“记录动作”。
3. 填写动作、数值、次数、组数和备注。
4. 选择训练肌群后保存。

### 查看历史

1. 点击首页右上角的“历史”。
2. 在搜索框输入动作名称或肌群名称。
3. 点击动作查看历史记录和趋势图。

### 在电脑上查看数据

1. 确认手机和电脑连接到同一个局域网。
2. 打开 App 底部的“局域网同步”。
3. 打开同步开关并复制页面显示的地址。
4. 在电脑浏览器中访问该地址。

### 分析食物

1. 在首页顶部“历史”旁点击相机图标。
2. 配置 DeepSeek API Key。
3. 选择“拍摄照片”或“从相册选择”。
4. 查看分析报告；需要调整时，编辑材料重量及每 100g 营养数据。
5. 点击保存，将结果与原图放入食物分析历史。

## 数据与隐私

- 数据默认只保存在本机应用目录中。
- 局域网同步仅在你主动打开后启用。
- 手机是唯一的数据源，电脑端主要用于查看、导出和导入。
- App 不依赖云端账户，不收集训练数据。
