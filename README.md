# GymStatistics

GymStatistics 是一款离线优先的个人健身记录应用。训练记录和计划留在手机上；需要分析食物时，再用 AI 相机拍照或从相册选图。

你可以按日期记录动作，在手动模式与按周重复的计划模式之间切换，通过统计页回顾训练频率、肌群覆盖和动作进步，也可以记录体重、围度及自定义身体指标，查看变化趋势。

内置麦当劳、老乡鸡与罗森离线营养库，支持搜索、收藏和配餐营养计算。AI 食物分析支持食物照片、配料表和营养成分表，需要网络连接及自行配置的 DeepSeek API Key。通过局域网同步，还可以在电脑浏览器中查看、导出和导入训练及身体数据。

## 主要功能

### 首页与营养库界面

- 首页采用中性背景、左对齐日期、轻量动作列表和紫色强调；点击动作可编辑，通过动作操作菜单可删除，拖动手柄仍可排序。
- 营养库使用独立品牌栏和紧凑商品列表，点击商品加号后在底部面板输入实际重量或份数、选择规格，再加入配餐；底部汇总可查看营养明细。
- 按重量计量的配餐支持修改已选商品重量；未知营养值仍显示为未知。

### 底部导航

- 底部依次为“首页”“计划”“身体”“统计”“动作库”五个栏位。
- “首页”保留日期选择、当天训练及“记录动作”，右上角提供营养库、AI 相机和设置入口。
- “计划”用于编辑每周训练计划；“动作库”用于搜索和查看已有历史动作。
- “身体”用于查看体重、围度及自定义身体指标的趋势和测量历史，点击“添加记录”进入独立录入页。
- “统计”用于查看训练概览、全年活动、肌群分布、计划训练量和动作曲线。
- 进入动作详情、相机和设置等二级页面时隐藏底部导航；切换栏位不会改变当前训练日期。

### 记录每日训练

- 按日期记录训练动作，每次添加一条动作记录。
- 支持重量、距离等数值，以及单位、次数、组数和备注。
- 记录默认保存到当前选中的日期，无需重复填写日期。
- 支持编辑和删除单条动作记录，删除前会进行确认。
- 可为动作选择训练肌群，之后可在历史记录中查看和修改。

### 快速切换日期

- 顶部日期栏可打开月历，支持切换月份和回到今天。
- 周日期栏可以快速选择一周内的日期，也可以左右滑动浏览前后整周；仅浏览周时不会改变当前训练日期。
- 在训练记录区域左右滑动即可切换前一天或后一天。
- 页面会跟随手指移动；松手时会结合拖动距离、速度和方向决定切换或回弹。

### 身体数据

- 点击底部“身体”进入统计主页，可选择指标，查看近 30 天、近 90 天或全部测量曲线、最新值及较上次测量的变化。缺失日期不补零，只有一次测量时显示单个点。
- 点击“添加记录”进入独立录入页，默认选择今天；首页周日期栏下方保留测量摘要和快捷入口，直接进入首页所选日期的录入页。
- 按天记录体重（kg），以及腰围、臀围、胸围、大腿围、小腿围、上臂围（cm）。每项可留空，未填写的数据不会补零或沿用昨天的数值。
- 可切换日期补记、修改，并在确认后删除当天记录；同一天只保留一份记录。
- 测量历史按日期从新到旧排列，点击某一天即可编辑。录入页隐藏底部导航，支持左右滑动切页动画；保存和删除成功后回到“身体”主页并刷新图表和历史。
- 保存期间不能返回，失败时保留输入以便重试；有未保存修改时，返回或更换日期前会提示确认。
- 右上角可管理指标：添加自定义名称和单位、改名、停用或重新启用。停用保留历史数据，已有记录的指标不能直接更改单位。
- 统计页“身体变化”可选择指标，查看近 30 天、近 90 天或全部记录的曲线，以及最新值和相对上次实际测量的变化。
- 身体记录保存在本机，不计为训练。JSON 备份包含身体数据和自定义指标；旧备份不含身体数据时，不会清空本机记录。重复日期可选择跳过或覆盖当天身体数据。

### 历史记录与趋势

- “动作库”页面会按动作名称汇总所有训练记录。
- 搜索支持动作名称和肌群名称，也支持中文、拼音、首字母及模糊匹配。
- 点击动作可查看全部历史记录。
- 动作详情中的记录默认按时间从新到旧排列，可切换为重量系数（数值 × 个数 × 组数）、数值、个数或组数排序，并切换升序或降序。
- 动作详情提供“查看该动作统计”按钮，跳转到“统计”的“动作进步”，自动选中当前动作并定位到曲线区域；返回可回到原动作详情。
- 点击历史记录即可将数据带回记录页面，方便再次使用。

### 训练计划

- 点击底部“计划”，进入按周一至周日重复使用的训练计划编辑页。
- 支持手动添加动作，也可以从历史动作中带入最近一次的重量、次数、组数和肌群等数据。
- 可在设置中切换“手动模式”和“计划模式”，默认进入手动模式。
- 计划模式中点击“完成并记录”会将预设动作写入当前日期；完成后的计划动作会折叠显示。
- 计划生成的实际记录会在手动模式中显示“计划”标识，并与普通记录使用同一套历史、编辑、删除和统计数据。
- 手动添加同名动作时会询问是否关联到当天尚未完成的计划动作。

### 肌群与疲劳提醒

- 动作可以关联一个或多个肌群。
- 同一肌群在最近严格不足 3 天内训练过时，会显示疲劳提醒。
- 疲劳提醒可以在动作详情页单独关闭。

### 训练统计

- 顶部概览展示累计训练天数、本月训练天数、连续训练周数及累计动作记录数。同一天的多条记录只算一个训练日。
- 最近一年的活动热力图可切换动作数和记录组数，左右滑动浏览全年，点击日期可查看摘要并跳转当天记录。
- 正面、背面人体图通过颜色深浅展示肌群覆盖组数，点击部位可联动查看排行；支持本周、近 30 天、近 90 天和全部记录，也可向前浏览历史周。
- 肌群图加载异常时会显示提示，可直接点击“重试”，无需退出统计页。
- 每周计划训练量将当前整周计划与本周实际记录对照，包含手动及计划生成的动作，不等同于计划完成率。
- 动作进步支持按动作或肌群名称搜索，分别查看数值、总个数、组数和重量系数。曲线按训练日期取每日最高值，不同单位分开显示，并可筛选时间范围。
- 最近训练展示最近六个训练日期，点击即可回到首页对应日期。
- 统计仅使用截至今天的实际动作记录，不计算未来记录和只有备注的空日期；修改、删除或导入记录后会同步更新。未填写组数时按一组计算。
- 连续周以周一至周日为一周，本周尚未训练不会立即打断上周延续的周数。肌群统计对每个选中肌群分别累计组数，不能直接相加作为全身总组数。
- 不估算体重、训练时长或生理恢复状态。

### 麦当劳离线营养库

- 点击首页右上角的餐具图标，进入“麦当劳营养库”；无需联网或配置 API Key。
- 支持分类浏览、名称搜索，以及小、中、大等不同规格选择。
- 93 款餐品均配有麦当劳官方图片，餐品列表与本次配餐中可离线查看。
- 点击餐品右上角星标可收藏或取消收藏；“收藏”分类支持搜索，收藏按餐品保存，不区分规格，重启应用后仍保留。
- 可同时添加同一餐品的多个规格，按半份增减数量（每项最多 99 份），也可移除单项或清空。
- 底部实时合计能量、蛋白质、脂肪、碳水化合物、钠和钙；未知值不会当作零。
- 按官网单份餐品计量，kcal 由 kJ ÷ 4.184 换算并四舍五入展示，不强行换算为每 100g。
- 当前内置 8 个分类、93 款餐品、137 种规格，采集于 2026 年 10 月 17 日；官网标注的营养数据更新时间为 2025 年 4 月，不代表实时在售菜单。
- “来源”可查看采集日期、官方更新时间及官网链接。实际份量、原料和配方可能变化，数据仅供参考。
- 当前配餐只在该页面使用，不会写入训练记录或食物分析历史，也不会自动替换 AI 结果。
- 内置数据随应用版本更新，不在后台自动访问官网。

### 老乡鸡离线营养库

- 在麦当劳营养库顶部切换至老乡鸡，支持菜品分类、搜索和收藏。
- 内置老乡鸡《菜品溯源报告 2.0》2026 年 4 月 30 日快照中的 191 条菜品数据，均按每 100 克显示。输入实际食用重量后可加入配餐并查看合计。
- 12 款名称匹配的菜品提供老乡鸡官方图片，其他菜品显示占位图。报告中的重名菜品按报告序号区分。
- 缺失或异常的营养值显示为未知，配餐合计不会将未知值当作零。整理数据尚未逐项核对报告原文，实际配方及菜单可能变化。
- 收藏和本次配餐分别保留各品牌的数据，不会写入训练记录或食物分析历史。
- 同一菜品再次加入配餐时，会使用新输入的重量替换原重量；“查看已选”中可移除单项或清空。
- 顶部“来源”可查看数据说明并打开[官方报告](https://github.com/lxjchina/lxj-trace/blob/main/references/report.pdf)。营养数据及已有图片均内置于应用，日常查询无需联网或 API Key。

### 罗森离线营养库

- 在营养库顶部切换至“罗森”，可浏览250款商品，支持分类、名称搜索、收藏及按实际食用重量计算配餐。
- 数据来自 FatSecret 中国站的第三方搜索摘要，整理于2026年10月29日，尚未逐项核验商品包装、地区配方或当前在售情况；分类按名称初步整理。
- 营养数据按每100克展示，由明确标注的来源克重换算，不将来源份量当作整包净含量。输入95克香肠面包时按原始95克一份的数据计算。
- 钠未在来源摘要中提供，显示为“未知”，不按零计算；原始份量、数值和来源链接随数据保留。
- 页面提供品牌来源说明和每款商品的来源链接；当前图片使用占位图，离线查询、收藏和计算无需 API Key。
- 切换三个品牌时分别保留本次搜索和配餐状态，收藏保存在本机；配餐不会写入训练或食物分析历史。

### AI 食物分析

在“首页”右上角点击相机图标，即可进入 AI 相机：

- 点击中央快门拍摄，或从左下角相册选择已有图片；右上角钥匙图标用于配置 API Key，右下角可查看食物分析历史。
- 识别食物、配料表和营养成分表。
- 相机预览会按屏幕比例居中裁剪，拍摄后的图片也会使用相同裁剪区域。
- 拍摄后先进入图片确认页面，可重新拍摄，也可以顺时针或逆时针旋转图片；确认后才会发送给 AI 分析。
- 相机控件进入时有淡入动效，按下快门与完成拍摄均有视觉反馈；旋转照片时会平滑过渡。
- 将能量、蛋白质、脂肪、碳水等数据统一按每 100g 展示。
- 分析完成后会显示包含原图、整份热量、三大营养素、食材明细和已有营养信息的报告。
- 每个食材可以单独修改重量及营养素系数，应用会重新计算整份食物的总重量、总热量和总营养素。
- 将确认后的结果与压缩后的原图保存到独立的“食物分析历史”，不会写入训练日期。
- 从食物分析历史打开报告、编辑食材或返回相机时，页面使用左右滑动转场。
- 使用前可通过相机钥匙按钮或首页右上角的“设置”配置 DeepSeek API Key，Key 会在本机加密保存。

二维码和条形码不会被用于查询营养数据。

### 离线优先

- 训练数据保存在手机本地。
- 没有网络也可以正常记录、查看和编辑训练。
- 不需要注册账号，也不会将数据自动上传到云端。

### 局域网同步

手机和电脑连接到同一个 Wi-Fi 或局域网后，可以从首页右上角的“设置”进入“局域网同步”：

- 手机作为数据源，电脑浏览器实时查看训练数据。
- 支持导出 JSON 和 CSV 文件。
- 支持从电脑选择 JSON 文件导回手机。
- 导入时可以选择全部导入或按日期导入；遇到重复日期会提示处理方式。
- 同步页面可以复制访问地址，默认端口为 `8931`。

## 使用方法

### 记录训练

1. 在首页选择训练日期。
2. 点击“记录动作”。
3. 填写动作、数值、次数、组数和备注。
4. 选择训练肌群后保存。

### 查看历史

1. 点击底部“动作库”。
2. 在搜索框输入动作名称或肌群名称。
3. 点击动作查看历史记录；点击“查看该动作统计”前往统计页查看该动作的曲线。
4. 在记录列表上方选择排序依据，点击旁边的顺序按钮切换正反顺序。

### 在电脑上查看数据

1. 确认手机和电脑连接到同一个局域网。
2. 点击首页右上角的设置图标，打开“局域网同步”。
3. 打开同步开关并复制页面显示的地址。
4. 在电脑浏览器中访问该地址。

### 查询营养与搭配餐品

1. 在首页右上角点击餐具图标，打开营养库。
2. 默认进入麦当劳，可在顶部按钮切换至老乡鸡或罗森；三个品牌分别计算本次配餐。
3. 按分类浏览或输入名称搜索，点击星标收藏，在“收藏”分类中再次查找。
4. 麦当劳点击商品加号后选择规格和份数，进入“查看已选”可按半份增减；老乡鸡和罗森先点击商品加号，在底部面板填写实际食用重量（克），再点击“加入配餐”。
5. 在底部查看合计，在“查看已选”中移除餐品或清空。麦当劳按官方每份数据计算，老乡鸡和罗森按每 100 克数据折算，未知营养值不按零计算。
6. 点击“来源”了解数据日期和出处。收藏在本机保存，本次配餐不会保存为食物分析历史。

### 分析食物

1. 在首页右上角点击相机图标。
2. 首次使用时，点击相机右上角的钥匙图标配置 DeepSeek API Key；也可提前从首页进入“设置”配置。
3. 点击中央快门拍照，或点击左下角“相册”选取图片。
4. 拍摄后先在确认页面检查图片，必要时旋转或重新拍摄；确认后才开始分析。从相册选图则直接开始分析。
5. 查看报告，按需单独修改食材重量及每 100g 的营养数据。
6. 点击“保存到食物分析历史”，保存结果和照片副本；分析结果不会自动加入当天训练记录。

## 数据与隐私

- 数据默认只保存在本机应用目录中。
- 拍摄照片经确认、或从相册选取图片后，应用会将图片发送给 DeepSeek。保存分析结果时，照片副本会保存在本机的食物分析历史中。
- 训练记录不需要网络连接；AI 食物分析需要网络连接和 DeepSeek API Key。
- 离线营养库使用应用内置的数据和图片；收藏只保存在本机，不包含在现有训练及身体数据备份中。查看外部来源链接时需要联网。
- 局域网同步仅在你主动打开后启用。
- 手机是唯一的数据源，电脑端主要用于查看、导出和导入。
- 无需注册应用账号；训练数据不会自动上传到云端。
